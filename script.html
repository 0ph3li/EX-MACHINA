Notes fromthe director

01does deus see all my code?+

only the repo you open it in, and only while you’re in the room. it doesn’t keep a copy, and it doesn’t train on your plot.

02will it push to main at 3 a.m.?+

never. it opens a pull request with notes and waits. the bow is yours, and so is the merge button.

03what if it’s wrong?+

it says so. every patch comes with the test that proves it, and when it isn’t sure it tells you its confidence instead of improvising.

04which languages does it speak?+

typescript, python, go, rust, java, ruby, php, swift, kotlin, c, c++, sql, and a little ancient greek. out loud it only speaks binary.

05is the bug really always on line 47?+

statistically, no. dramatically, yes.
